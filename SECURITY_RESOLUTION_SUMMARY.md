## Overview

## Vulnerabilities Resolved

### 1. Quill XSS Vulnerabilities (2 Moderate Severity Issues)

**Status:** ✅ FIXED

#### Issues:
- **GHSA-4943-9vgg-gr5r**: Cross-site Scripting in quill ≤1.3.7
- **GHSA-v3m3-f69x-jf25**: Quill vulnerable to XSS via HTML export feature in v2.0.3

#### Resolution:
- Downgraded `quill` from `2.0.3` to `2.0.2` (secure version)
- Added npm `overrides` to force `react-quill` to use secure `quill@2.0.2`
- Both direct and transitive dependencies now use the patched version

#### Impact:
- XSS vulnerabilities in the rich text editor have been eliminated
- No breaking changes - quill 2.0.2 is fully compatible

### 2. Apollo Server Deprecation & DoS Vulnerability

**Status:** ✅ FIXED

#### Issues:
- `@apollo/server@4.x` - End of Life (January 26, 2026)
- `apollo-server-express@3.x` - End of Life, no longer supported
- `@apollo/server@5.0.0` - Vulnerable to DoS attack (GHSA-mp6q-xf9x-fwf7)

#### Resolution:
- Upgraded `@apollo/server` from `4.10.5` to `5.4.0` (secure, stable)
- Removed `apollo-server-express` (unused dependency)
- Pinned version to avoid unexpected updates
- Added Node.js >= 20 requirement to `engines` field (required by Apollo v5)

#### Impact:
- Using actively maintained, secure version of Apollo Server
- DoS vulnerability avoided
- No functionality changes - package was not actively used in codebase
