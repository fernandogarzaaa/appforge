Usage: base44 link [options]

Link a local project to a Base44 project (create new or link existing)

Options:
  -c, --create                     Create a new project (skip selection prompt)
  -n, --name <name>                Project name (required when --create is
                                   used)
  -d, --description <description>  Project description
  -p, --projectId <id>             Project ID to link to an existing project
                                   (skips selection prompt)
  -h, --help                       display help for command
