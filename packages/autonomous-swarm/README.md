# Autonomous Swarm

AI-powered autonomous code assistant with 6 intelligent agents that proactively monitor, analyze, and improve your codebase.

## Features

- **6 Autonomous Agents:**
  - 🛡️ **Sentinel**: Security scanner
  - 🐞 **BugHunter**: Bug detector
  - ⚡ **Optimizer**: Performance analyzer
  - 👔 **ProductOwner**: Feature strategist
  - 🧙‍♂️ **GodMode**: Quantum orchestrator
  - 🌀 **Antigravity**: AI collaboration layer

- **Autonomous Operation**: Runs every 5 minutes without manual intervention
- **Quantum-Powered Decisions**: Uses quantum-inspired AI for optimal solutions
- **VS Code Integration**: Native extension with status panel

## Installation

```bash
npm install -g @appforge/autonomous-swarm
```

## Quick Start

```bash
# Initialize swarm in your project
autonomous-swarm init

# Start autonomous monitoring
autonomous-swarm start

# View agent activity
autonomous-swarm status
```

## VS Code Extension

Install from marketplace: "Autonomous Swarm"

## Configuration

Create `.swarmrc` in your project root:

```json
{
  "llm_provider": "openai",
  "api_key": "your-key-here",
  "interval_minutes": 5,
  "enabled_agents": ["all"]
}
```
