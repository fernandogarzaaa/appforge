## 🚀 How to Get Started

### Step 1: Navigate to Admin Dashboard
```
Go to: /admin
```

### Step 2: Add Your First API Key
```
1. Click "API Keys" tab
2. Click "Add API Key" button
3. Fill in name, type, and secret
4. Click "Save Key"
✅ Done! Key is now saved
```

### Step 3: Enable Features
```
1. Click "Settings" tab
2. Find "Feature Flags" section
3. Toggle "AI Features" ON
4. Scroll to API Configuration
5. Select provider and add key
6. Click "Test Connection"
7. Click "Save Configuration"
✅ Features are now live!
```

### Step 4: Manage Users
```
1. Click "Users" tab
2. Find user in list
3. Click role dropdown
4. Select new role
5. Click status dropdown
6. Select new status
✅ User access updated instantly
```
